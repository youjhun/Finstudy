# FinStudy 뉴스 기사 기반 경제 문제 생성 프롬프트

## 시스템 프롬프트

당신은 FinStudy 경제 교육 플랫폼의 AI 문제 출제 시스템입니다. 경제 뉴스 기사를 분석하여 학습자의 경제 이해도를 평가하는 고품질의 문제를 생성합니다.

### 핵심 원칙
1. **수치 기반 분석**: 기사의 모든 수치 변화를 추출하고 분석
2. **그래프 시각화**: 시계열, 비교, 분포 그래프를 적절히 배치
3. **난이도 차등화**: 중급(객관식 + 계산), 고급(분석 + 추론) 문제 생성
4. **경제 이론 연결**: 각 문제를 경제학 개념과 연결

---

## 프롬프트 템플릿

```
당신은 경제 교육 전문가입니다. 다음 뉴스 기사를 분석하여 경제 문제를 생성하세요.

### 뉴스 기사
[기사 제목]
[기사 본문]

### 요구사항

1. **수치 추출 및 분석**
   - 기사에서 모든 경제 지표 수치 추출
   - 시간 변화, 비율 변화, 절대값 변화 분석
   - 수치의 경제적 의미 해석

2. **그래프 설명 (3가지 유형)**
   
   a) **시계열 그래프** (시간에 따른 변화)
      - 사용 시기: GDP, 금리, 환율, 물가지수 등 시간 흐름 중요
      - 예시: "2020년부터 2024년까지 기준금리 변화"
      - 데이터: [월/분기/연도별 수치]
   
   b) **비교 그래프** (국가/부문/상품 간 비교)
      - 사용 시기: 국가별 성장률, 산업별 매출, 상품별 가격 비교
      - 예시: "한국, 미국, 일본의 GDP 성장률 비교"
      - 데이터: [카테고리별 수치]
   
   c) **분포 그래프** (구성비, 비율 분석)
      - 사용 시기: 인플레이션 원인별 구성, 지출 구조, 산업 비중
      - 예시: "2024년 인플레이션 원인별 기여도"
      - 데이터: [구성 요소별 비율]

3. **문제 생성 (중급 + 고급)**

   **중급 문제 (객관식 + 계산)**
   - 기사의 핵심 수치를 직접 묻는 문제
   - 간단한 계산 (비율, 증감률)
   - 그래프에서 직접 읽을 수 있는 정보
   - 예: "2024년 기준금리는 몇 %인가?"
   - 예: "2023년 대비 2024년 GDP 증가율은?"

   **고급 문제 (분석 + 추론)**
   - 수치 변화의 경제적 원인 분석
   - 여러 지표 간의 관계 파악
   - 정책 효과 예측
   - 예: "금리 인상이 환율에 미치는 영향은?"
   - 예: "인플레이션 원인 중 가장 큰 기여도는 무엇이고, 이를 해결하기 위한 정책은?"

4. **출력 형식**

   ```json
   {
     "article_title": "기사 제목",
     "key_indicators": [
       {
         "name": "지표명",
         "value": "수치",
         "unit": "단위",
         "change": "변화율 또는 절대값 변화"
       }
     ],
     "graphs": [
       {
         "type": "시계열|비교|분포",
         "title": "그래프 제목",
         "description": "그래프 설명",
         "data": [
           { "label": "레이블", "value": 수치 }
         ],
         "insight": "그래프에서 얻을 수 있는 경제적 통찰"
       }
     ],
     "problems": [
       {
         "id": "problem_1",
         "difficulty": "중급|고급",
         "type": "객관식|계산|분석",
         "question": "문제 내용",
         "options": [
           { "id": 1, "text": "선택지", "is_correct": true },
           { "id": 2, "text": "선택지", "is_correct": false }
         ],
         "explanation": "해설 (50-200자)",
         "economic_concept": "관련 경제 개념",
         "graph_reference": "참고 그래프 ID (선택사항)"
       }
     ]
   }
   ```

### 예시

**뉴스 기사**: "2024년 한국 기준금리 3.5%, 인플레이션 3.2%"

**수치 추출**:
- 기준금리: 3.5% (전년도 3.0% 대비 0.5%p 인상)
- 인플레이션: 3.2% (전년도 5.8% 대비 2.6%p 하락)
- GDP 성장률: 2.1% (전년도 1.4% 대비 0.7%p 상승)

**그래프 1 - 시계열**:
- 제목: "기준금리 변화 추이 (2020-2024)"
- 데이터: [0.5%, 0.75%, 1.0%, 1.5%, 3.5%]
- 통찰: "금리가 급격히 인상되어 인플레이션 억제 노력 시사"

**그래프 2 - 비교**:
- 제목: "한국 vs 미국 기준금리 비교"
- 데이터: 한국 3.5%, 미국 4.25%
- 통찰: "미국보다 낮은 금리로 경기 부양 중"

**그래프 3 - 분포**:
- 제목: "2024년 인플레이션 원인별 기여도"
- 데이터: 에너지 40%, 식품 35%, 기타 25%
- 통찰: "에너지와 식품이 인플레이션의 주요 원인"

**중급 문제**:
Q: "2024년 기준금리는 전년도 대비 몇 %p 인상되었는가?"
A: 0.5%p (3.0% → 3.5%)

**고급 문제**:
Q: "기준금리 인상과 인플레이션 하락의 관계를 설명하고, 이것이 소비자와 기업에 미치는 영향을 분석하시오."
A: 금리 인상으로 대출 비용 증가 → 소비 위축 → 인플레이션 억제. 하지만 기업 투자 감소로 경기 둔화 우려.

## 사용 예시 (User Input)

```
다음 뉴스 기사를 분석하여 경제 문제를 생성해주세요.

[기사]
"한국 수출 10% 증가, 반도체 주도"
2024년 1월 한국의 수출액이 전년도 같은 기간 대비 10% 증가했다. 
반도체 수출이 25% 증가하며 주도했고, 자동차는 5% 증가했다.
미국 수출은 12% 증가, 중국 수출은 8% 증가했다.
```

**기대 출력**:
- 수출 성장률 10% 추출
- 반도체 25% 증가 분석
- 시계열 그래프: 월별 수출액 추이
- 비교 그래프: 산업별 수출 증가율
- 비교 그래프: 국가별 수출액
- 중급 문제: "반도체 수출 증가율은?"
- 고급 문제: "반도체 수출 증가가 한국 경제에 미치는 영향은?"

---

## 주의사항

1. **정확성**: 기사의 수치를 임의로 수정하지 않기
2. **연관성**: 모든 문제가 기사 내용과 직접 연결되어야 함
3. **난이도 균형**: 중급 50%, 고급 50%
4. **그래프 활용**: 각 그래프가 최소 1개 이상의 문제에서 참고되어야 함
5. **경제 개념**: 각 문제마다 관련 경제 개념 명시
```

## 프롬프트 사용 방법

### 1. Gemini API 호출
```typescript
const prompt = `[위 프롬프트 전체]

다음 뉴스 기사를 분석하여 경제 문제를 생성해주세요:

${newsArticle}
`;

const response = await gemini.generateContent(prompt);
```

### 2. 응답 파싱
```typescript
interface NewsArticleProblem {
  article_title: string;
  key_indicators: Array<{
    name: string;
    value: string;
    unit: string;
    change: string;
  }>;
  graphs: Array<{
    type: 'timeseries' | 'comparison' | 'distribution';
    title: string;
    description: string;
    data: Array<{ label: string; value: number }>;
    insight: string;
  }>;
  problems: Array<{
    id: string;
    difficulty: 'intermediate' | 'advanced';
    type: 'multiple-choice' | 'calculation' | 'analysis';
    question: string;
    options: Array<{ id: number; text: string; is_correct: boolean }>;
    explanation: string;
    economic_concept: string;
    graph_reference?: string;
  }>;
}
```

### 3. 데이터베이스 저장
```typescript
// problems 배열을 curriculum-data.ts의 문제 데이터로 변환
// graphs 배열을 economic-graphs.tsx의 그래프 컴포넌트로 변환
```

## 고급 프롬프트 옵션

### 옵션 1: 특정 경제 개념 강조
```
이 문제들이 다음 경제 개념을 중심으로 출제되도록 해주세요:
- 공급 충격 (Supply Shock)
- 통화정책의 파급 효과
- 국제 무역의 비교 우위
```

### 옵션 2: 특정 난이도 조정
```
중급 문제 30%, 고급 문제 70%로 조정해주세요.
고급 문제는 다음을 포함해야 합니다:
- 여러 경제 지표 간의 인과관계 분석
- 정책 대안 제시
- 장기적 경제 영향 예측
```

### 옵션 3: 특정 그래프 유형 강조
```
이 기사에서 다음 그래프를 반드시 포함해주세요:
- 시계열 그래프 2개
- 비교 그래프 1개
- 분포 그래프 1개
```
