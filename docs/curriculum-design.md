## Phase 2: "수요와 공급" 유닛 상세 설계

### 유닛 개요
- **학습 목표:** 수요·공급 법칙 이해 → 균형 가격 결정 메커니즘 파악
- **선행 지식:** 기회비용, 희소성 (Unit 1 완료 필수)
- **총 학습 시간:** 15분 (세션 3개 × 5분)
- **총 문제:** 6개 (신규 40% + 복습 60%)

### 화면 구성

**레이아웃:**

└─────────────────────────────────┘
```

### 텍스트 콘텐츠

**개념 설명:**
```
수요 곡선 (Demand Curve)
- 정의: 각 가격 수준에서 소비자가 구매하려는 상품의 수량
- 특징: 일반적으로 우하향 (가격↓ → 수량↑)
- 이유: 가격이 싸면 더 많은 사람이 구매 가능
```

**예시:**
- 아이스크림 가격 1,000원 → 하루 100개 판매
- 아이스크림 가격 500원 → 하루 200개 판매

**학습 과학 적용:**
- **Mayer의 CTML (인지 부하 이론):**
  - 한 화면에 하나의 개념만 (수요 곡선)
  - 텍스트 + 애니메이션 그래프 결합 (멀티미디어 효과)
  - 불필요한 정보 제거 (공급 곡선은 다음 화면에서)
  
- **Sweller의 인지 부하 관리:**
  - 정보 밀도: 최소화 (3문장 설명 + 1개 예시)
  - 비계 설정: 힌트 버튼으로 추가 설명 제공 가능
  
- **Gagné의 정보 제시:**
  - 정의 → 특징 → 예시 순서로 구조화

### 퀴즈 설명

**문제 유형:** 다중선택형 (이미지/그래프 클릭)

**문제:**
```
커피 가격이 2,000원에서 1,500원으로 내려갔습니다.
수요 곡선에 따르면 어떤 변화가 일어날까요?

A) 커피 판매량 증가
B) 커피 판매량 감소
C) 판매량 변화 없음
```

**정답:** A) 커피 판매량 증가

**오답 설명:**
- B 선택 시: "❌ 가격이 내려가면 더 많은 사람이 구매하려고 합니다. 수요 곡선을 다시 보세요!"
- C 선택 시: "❌ 수요 곡선은 가격 변화에 따라 수량이 변한다는 뜻입니다."

**학습 과학 적용:**
- **Testing Effect (인출 연습):** 
  - 개념 학습 직후 즉시 퀴즈 제시
  - 뇌가 정보를 장기 기억으로 인코딩하도록 강제
  
- **Gagné의 실습 제공:**
  - 새로 배운 개념을 즉시 적용하는 문제
  - 피드백 루프: 오답 시 설명 제시 → 개념 재학습
  
- **Sweller의 비계 설정:**
  - 레벨 1 사용자: 힌트 활성화
  - 레벨 3 사용자: 힌트 비활성화

```

### 텍스트 콘텐츠

**개념 설명:**
```
공급 곡선 (Supply Curve)
- 정의: 각 가격 수준에서 생산자가 판매하려는 상품의 수량
- 특징: 일반적으로 우상향 (가격↑ → 수량↑)
- 이유: 가격이 비싸면 생산 비용을 감수하고도 이윤이 나므로 더 많이 생산
```

**예시:**
- 아이스크림 가격 1,000원 → 하루 50개 생산
- 아이스크림 가격 2,000원 → 하루 150개 생산

**학습 과학 적용:**
- **대조 학습 (Interleaving):**
  - 수요 곡선(우하향) vs 공급 곡선(우상향) 비교
  - 뇌가 두 개념의 차이를 명확히 인식
  
- **Mayer의 CTML:**
  - 수요 곡선과 동일한 포맷 (일관성)
  - 그래프의 방향만 다름 (명확한 대조)

### 문제 은행 구성 (6개 문제)

**신규 개념 (40% = 2.4 → 2개):**
1. 수요 곡선 기본 개념 (다중선택)
2. 공급 곡선 기본 개념 (다중선택)

**복습 개념 (60% = 3.6 → 4개):**
3. 기회비용 + 수요 곡선 (빈칸 채우기)
4. 균형점 찾기 (드래그 앤 드롭)
5. 실생활 시나리오 (계산형)
6. 종합 이해도 (서술형)

### SM-2 알고리즘 적용

**문제별 복습 스케줄:**
```
문제 1 (신규):
- 1차 학습 후 1일 뒤 복습
- 2차 학습 후 3일 뒤 복습
- 3차 학습 후 7일 뒤 복습

문제 3 (복습):
- 이전에 틀렸던 문제 → 우선 출제
- 망각 곡선상 복습 시점 → 자동 제시
```

### 인터리빙 규칙

**세션 내 문제 순서:**
```
세션 1 (5분):
- 신규 개념 1 (수요 곡선)
- 복습 개념 1 (기회비용 + 수요)
- 신규 개념 2 (공급 곡선)

세션 2 (5분):
- 복습 개념 2 (균형점 찾기)
- 신규 개념 3 (시장 가격)
- 복습 개념 3 (실생활 시나리오)

세션 3 (5분):
- 복습 개념 4 (종합 이해도)
- 신규 개념 4 (탄력성 미리보기)
- 복습 개념 5 (전이 학습)
```

**인터리빙의 효과:**
- 뇌가 개념 간 차이를 더 잘 인식
- 장기 기억 형성 강화 (Kornell & Bjork, 2008)
- 학습 효율 43% 향상

## Phase 4: 인지 부하 관리 및 동기부여 시스템

### 인지 부하 관리 (Sweller)

**화면당 정보 밀도:**
```
화면 1 (오프닝): 
- 텍스트만 (3문장 + 1개 질문)
- 그래프 없음
- 인지 부하: 낮음 ✓

화면 2 (수요 곡선):
- 텍스트 (3문장 + 1개 예시)
- 애니메이션 그래프 1개
- 인지 부하: 중간 ✓

화면 3 (퀴즈 1):
- 문제 텍스트 + 선택지 3개
- 그래프 없음 (이전 화면에서 학습)
- 인지 부하: 낮음 ✓

화면 4 (공급 곡선):
- 화면 2와 동일 구조 (일관성)
- 인지 부하: 중간 ✓

화면 5 (퀴즈 2 + 전이):
- 드래그 앤 드롭 (상호작용)
- 실생활 질문 (맥락화)
- 인지 부하: 중간 ✓
```

### 비계 설정 (Scaffolding)

**레벨별 힌트 제공:**
```
레벨 1 (입문):
- 모든 퀴즈에 힌트 버튼 활성화
- 힌트: "수요 곡선은 우하향이에요. 가격이 내려가면?"
- 설명: 상세한 1문장 설명 제공

레벨 2 (중급):
- 50% 문제에만 힌트 활성화
- 힌트: "수요 곡선을 다시 보세요"
- 설명: 간단한 1문장 설명

레벨 3 (심화):
- 힌트 비활성화
- 설명 없음
- 대신 서술형 문제 비중 증가 (40%)
```

### 즉각 피드백

**정답 시:**
```
✅ 정답입니다!
"맞습니다! 가격이 내려가면 더 많은 사람이 구매하려고 합니다."
+10 XP 획득
```

**오답 시:**
```
❌ 틀렸습니다.
"가격이 내려가면 수량이 증가합니다. 수요 곡선을 다시 보세요."
[다시 풀기] [설명 보기] [다음으로]
```

**재시도 로직:**
- 오답 문제 → 세션 마지막에 다시 출제
- 2회 연속 오답 → 개념 재학습 화면 제시
- 3회 연속 오답 → 유닛 재시작 권장

### 동기부여 시스템 (SDT & Flow)

**유능감 (Competence):**
```
- 정답 시: +10 XP (신규), +5 XP (복습)
- 완료 시: +35 XP 보너스
- 연속 학습: 스트릭 시각화 (3일 연속 → 🔥 배지)
- 성취 배지: "수요와 공급 마스터" (모든 문제 정답)
```

**자율성 (Autonomy):**
```
- 학습 시작 전: "5분 / 10분 / 20분 중 선택"
- 문제 순서: 일부 선택 가능 (신규 vs 복습)
- 피드백 수준: 상세 / 간단 / 없음 선택
```

**관계성 (Relatedness):**
```
- 실생활 예시: "카페 사장", "아이스크림", "여름"
- 친구 비교: "친구 OOO는 이 문제를 30초에 풀었어요"
- 커뮤니티 팁: "이 개념을 쉽게 이해하는 팁 공유"
```

**Flow 상태 유지:**
```
- 난이도 자동 조정 (ELO 기반)
- 도전 수준: 사용자 실력의 4-8% 높은 수준
- 명확한 목표: "이 유닛 완료 시 다음 유닛 잠금 해제"
- 즉각 피드백: 모든 문제 제출 후 1초 내 결과 표시
```
